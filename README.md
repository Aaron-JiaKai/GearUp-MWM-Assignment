# GEARUP - An e-commerce website coded in ASP.NET

A project developed for my Mobile & Web Multimedia assignment. This website is coded in C# using ASP.NET. As part of assignment requirements, the project is developed for both desktop and mobile aspect ratios.

## ✨ Features

Guests of the website can:
-	Browse the product catalog on the website.
-	View the product in more detail.
-	See reviews of products left by other buyers.
-	Leave feedback on the website to admin.
-	Register and login as a member.

Members can:
-	Login to their member account.
-	Manage their user profile.
-	Add products from the catalog into their shopping cart.
-	Modify the contents of the shopping cart.
-	Checkout their order.
-	View order history.
-	Cancel pending orders.
-	Mark shipped orders as received.
-	Give reviews to orders once the order is completed.

Admin can:
-	Login as an admin.
-	View the users registered on the site and their details.
-	Disable the user’s account.
-	Manage the categories of products on the website.
-	Manage the product details for sale on the website.
-	Mark the pending orders made by members as shipped.
-	View the details of orders that are delivered and rated.
-	View the feedback received by guests of the website.

2. Open the solution file (.sln) in Visual Studio.
3. Press F5 or click Start Debugging to run the application.
